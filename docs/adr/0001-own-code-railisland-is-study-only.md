# Write our own code; railisland is for study only

railisland ([siriushsu/taiwan-rail-live](https://github.com/siriushsu/taiwan-rail-live)) is the model for this project, but its licence is source-available, not open source: any public site built on all or a substantial part of its code, ports included, needs the author's written consent. We write our own code and take only ideas from it (speed profiles fitted so Trains arrive on time, eased Delay changes with speed caps, station boards, nearby Trains). No railisland code is copied, and the "Rail Island" / 軌島 names aren't used.

## Considered Options

- **Ask the author for consent to port it.** Rejected: the engine is mixed into a 31,000-line inline script (the author's own tools cut functions out of `index.html` to reuse them), and the project would depend on someone else's goodwill.
