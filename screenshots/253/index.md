# #253 sign-off shots

Branch `253-cercanias-nucleos` at 08eae39, built for the web and served locally. The bundle is the branch's dry run of 7 Oct 2026; the `-main` shots are main's dry run on the same cached feeds and OpenStreetMap download. Each shot serves one of 30 snapshots made from Renfe's live files captured between 19:51 and 20:21 UTC on 7 Oct, run through the branch's fetcher step, with the clock fixed 5 s after the snapshot, so Live Trains show and stand still. Only Renfe's files were captured, so FGC's, TRAM's and the Metro's Trains run Scheduled. The snapshot for each place is the one with the most of that núcleo's Trains in view (ties: more Live), except 46-Ujo, kept on a snapshot with its Train mid-frame. Desktop shots were taken at 1440×900 and pixel ratio 2 and are scaled to 50% here (1440×900 px); light theme, no CPU throttle; 21 is dark; 60 and 61 are a phone (390×844 at pixel ratio 3, full size). Waits: Trains, then a Live Train, then the map's tiles loaded three times 1.5 s apart. Spot numbers are those of the spots list on #253, and the issues named are its follow-ups.

No `pageerror` and no console error on any page; the only console output is the basemap style's warnings (`highway-shield-non-us`, `highway-shield-us-interstate`, `road_shield_us` filters on every page, `circle-11` in dark), the same on main's bundle. No request went unanswered (no `alerts.json` or `report.json` asked for). "updated Oct 6, 2026" in the credits comes from the dry run's manifest, which still names 6 Oct's live day.
