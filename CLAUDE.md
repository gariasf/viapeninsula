## Agent skills

### Issue tracker

GitHub Issues for this repo, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`); each label string equals its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Roadmap

Choosing, claiming or filing an issue: GitHub milestones order the work, and a follow-up is filed only when it's critical or major. See `docs/agents/roadmap.md`.

### Checks and resources

Checking a change, driving a browser, or launching an agent: size it to the ticket type. See `docs/agents/checks-and-resources.md`.
